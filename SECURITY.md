# Security Policy

## Reporting

Report vulnerabilities in this fork privately via GitHub Security Advisories on
this repository. Do not open a public issue for security reports.

For vulnerabilities in upstream PrivateBin, report them to the
[PrivateBin project](https://github.com/PrivateBin/PrivateBin/security/advisories/new)
instead.

## Response

Reports are reviewed as soon as practical. Valid issues get a private advisory
and a fix release when needed.
